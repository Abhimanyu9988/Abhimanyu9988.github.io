# About the author (true facts only)

The article writer may use these for one or two personal lines. Nothing else about Abhi may be invented.
Edit this file whenever you like; the next draft picks it up.

- I lead a support engineering team for observability agents that run inside Kubernetes clusters: EKS, AKS and
  OpenShift.
- Most of my week goes on one question: why does something that looks correctly configured not work in a real
  cluster?
- I work a lot with the OpenTelemetry Collector and with Java, Node.js and .NET instrumentation, and I contribute
  to OpenTelemetry open source.
- Before I write about a problem, I reproduce it myself in a throwaway AWS account and keep the raw output.
- My best-performing post so far was a hands-on build guide: a universal Prometheus-to-APM integration that lets you
  monitor any application with zero code changes. Most of its readers found it through Google or a link someone
  shared directly. Readers come for posts that teach them to build something they can use at work.
